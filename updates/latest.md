## החלטות של תומר

ערך ← שחרור ← שוטטות ← קשב ← הבחנה ← יצירה ← חגיגה

Value → Release → Wandering → Attention → Discernment → Creation → Celebration

- זה רצף חי וחוזר, ולא נוהל לינארי קשיח.
- **חגיגה** היא תנועה מסיימת שנשענת על הכרת תודה.
  - היא מכירה במה שנפגש, במה שהתאפשר, במה שנלמד, ובאנשים, ביחסים ובנסיבות שתרמו לכך.
  - היא איננה דוח ואיננה הערכה.
  - היא שומרת את האפשרות לחזור אל הערך המקורי בהבנה שהשתנתה.
  - עדיין אין לה תרגיל מבוסס או מקור.

### החלטות קודמות

- שוטטות היא שיטה עצמאית. "עושים קהילה" הוא שדה יישום אחד שלה.
- ששת הקשרי הכניסה (חינוכי, קהילתי, האמן, המדען, העסקי, היחיד) הם פתחים לשיטה אחת משותפת.
- חמש המשבצות של המנגנון (כניסה, תנועה, הבחנה, עקבה, חזרה) הן מבנה של תרגול אחד, ולא השיטה.
- השיטה מוצגת כפרקטיקה מתפתחת, ולא כתאוריה מתוקפת מדעית.
