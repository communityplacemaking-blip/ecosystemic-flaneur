# The Ecosystemic Flâneur / המשוטט האקוסיסטמי

The public home of Tomer's wandering methodology: its movement, roots, practices, workshops and open research questions. It is a developing practice, not a validated theory.

- `index.html` is the methodology page, in Hebrew and English. It is currently a draft, with source marks that can be switched off.
- `updates/latest.md` is the current status of the work, rewritten at each update.

The page is served with GitHub Pages.
