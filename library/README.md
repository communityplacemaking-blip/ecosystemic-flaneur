# ספריית התרגולים (שלב 2: יסודות)

הבסיס לספרייה שהמשוטט יאצור ממנה מסעות. **אף עמוד באתר לא משתמש בה.** גרסה B ממשיכה לעבוד מהנתונים שבתוכה, בלי שינוי, והספרייה לא מתפרסמת כחלק מהאתר.

## מבנה

```
library/
  practices/       קובץ JSON אחד לכל תרגול (25 קבצים, הועברו מ-B)
  sources/         רישום המקורות. כל תרגול מפנה אליו
  dictionaries/    הרשימות שמותר לתייג בהן: שלבים, תנועות, קהלים, מרחבים, כוונות,
                   גבולות, הקשרי כניסה, סוג מקור, מצב תיעוד, ציר הקשב, איכויות הקשב
  proposals/       הצעות תיוג שממתינות לאישור. לא נכנסות לרשומות לפני אישור
  reports/         דוח ההעברה (נוצר אוטומטית)
  tools/           קריאת B, העברה, אימות, בנייה, דוח
  tests/           בדיקות העברה ובדיקות אימות
```

## רשומת תרגול

| חלק | מה יש בו |
|---|---|
| `id`, `name`, `kind` | זהות. kind הוא practice או lens |
| `origin` | סוג המקור: לא הוכרע (ברירת מחדל), מקורי, עיבוד, חיצוני, בפיתוח. "מקורי" ו"עיבוד" מחייבים החלטה מתועדת |
| `documentation` | מצב התיעוד מ-B, טקסט המקור המקורי, והפניות לרישום המקורות |
| `content` | נוסח ההזמנה, נוסחי לשון פנייה, הערה למנחה |
| `placement` | חמשת השלבים (slots) ושבע התנועות (movements). שתי שכבות נפרדות |
| `attention` | ציר, כיוון, מגוון ועומק מ-B, ואיכויות הקשב: קטגוריה יציבה ותיאור חופשי |
| `fit` | כוונות, קהלים, מרחבים, משך מינימלי, האם מונחה בלבד, אופן שילוב |
| `care` | תגיות גבול |
| `output`, `engine` | שדות של B שמופיעים רק ברשומה אחת (includesTrace, core) |
| `review` | מצב הבדיקה של הרשומה |

שדה שחסר ברשומה נשאר חסר. האימות מדווח עליו כאזהרה, ולא ממלא אותו.

## איכויות הקשב: אוצר מילים פתוח

`dictionaries/attention-qualities.json` מחזיק קטגוריות יציבות שהמנוע קורא, ורשימת `emerging` לאיכויות חדשות. כל איכות ברשומה היא `{ category, text }`: הקטגוריה למנוע, והתיאור במילים חופשיות. איכות חדשה נרשמת קודם כ-emerging עם `category: null`, ורק אחר כך, אם יוחלט, הופכת לקטגוריה.

## פקודות

```
cd library
npm test              בדיקות העברה ואימות
npm run validate      אימות הספרייה (עם --warnings: גם מה שחסר)
npm run build         איחוד לקובץ build/library.json (לא נשמר במאגר)
npm run report        עדכון דוח ההעברה
```

Node 22 ומעלה. אין תלויות חיצוניות.
